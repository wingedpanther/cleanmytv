# Community themes

Themes people made and shared. The desktop app lists every `.cmtvtheme` file in this folder under
Themes, and one click puts that look on the TV.

## Adding yours

1. Get the look right on your TV, then in the desktop app use **Save this look…** on the Themes card.
2. Open the file in a text editor:
   - add `"author": "your GitHub name"` next to `"name"`;
   - take out `"wallpaper"` if it's there. Community themes carry the look only, so they stay small and
     leave the owner's own picture alone.
3. Put the file in this folder and open a pull request. One theme per file, named after the theme.

`npm test` checks that every file here loads.
